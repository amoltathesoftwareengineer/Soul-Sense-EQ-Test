# Soul Sense EQ Test

An interactive emotional intelligence self-assessment application designed to encourage self-reflection and awareness of emotional skills.

## Overview

Soul Sense EQ Test provides scenario-based questions that help users reflect on emotional awareness, emotional regulation, empathy, and interpersonal communication.

The application generates a summary of responses and suggests learning activities based on the selected assessment framework.

The results are intended for personal reflection and are not clinical or psychological diagnoses.

## Key Features

- Interactive multiple-choice assessments
- Scenario-based questions
- Emotional intelligence skill categories
- Automatic score calculation
- Category-wise result summaries
- Personalized learning suggestions
- Responsive interface
- Optional assessment history

## Installation

```bash

cd Soul-Sense-EQ-Test
npm install
npm run dev
```

Open the local development URL displayed in the terminal.

## Assessment Workflow

1. Start an assessment.
2. Answer scenario-based questions.
3. Review the calculated category scores.
4. Explore self-reflection suggestions.
5. Retake the assessment when desired.
